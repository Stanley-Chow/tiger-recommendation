**Amazon Beauty 2014 — M3 tokenizer ablation.** Test Recall@100 and MAP@20 for HKM, RQ-VAE and their full-code permutation controls. Large diamonds show the mean and whiskers show ±1 sample standard deviation across 3 pipeline seeds (42, 43, 44). Small points show the individual seeds. Each arm uses the same 22,225 frozen test contexts and excludes the entire previously seen item history. The same users recur across seeds; SD describes pipeline variation rather than user-level uncertainty or a confidence interval. Per-seed paired user bootstrap comparisons are saved separately; users across seeds are not pooled as independent observations. Whole-code permutation preserves the code set, vocabulary and catalog prefix occupancy, while interaction-weighted exposure can change. Single-positive MAP@20 equals reciprocal rank when the held-out item appears within the first 20 results, and zero otherwise.
