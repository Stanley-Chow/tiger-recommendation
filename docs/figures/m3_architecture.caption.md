**M3 tokenizer experiment structure.** Product metadata for the warm training catalog is encoded once with frozen 384-dimensional MiniLM vectors. Fixed hierarchical k-means (HKM) and learned residual quantization (RQ; three 16-entry codebooks) produce three semantic tokens plus a deterministic collision suffix. RQ fits a metadata-only reconstruction/codebook/commitment objective, selecting an epoch count on a 90/10 metadata split before fresh full-catalog refitting. Each tokenizer is paired with a permutation of complete codewords, including suffixes; each pair preserves its code set and trie topology while changing item-content alignment; interaction-weighted token exposure can also change. All three RQ tokenizers are fitted before code mappings and a common vocabulary are frozen. Four arms use three paired pipeline seeds (42, 43, 44), fresh Transformer weights and identical model dimensions. Their separate next-item objective is teacher-forced full-vocabulary token cross entropy. Epoch selection uses the same 1,000-user recommendation-validation cohort: maximize Recall@100 subject to MAP@20 at least validation popularity; retain a reported fallback if no epoch passes. All 12 selected checkpoint hashes are saved before any test retrieval. Trie-constrained beam search uses width 200 and excludes the full warm seen-item history. Final testing includes all eligible warm-target users, with cold targets excluded by the frozen preprocessing protocol. Primary contrasts use Recall@100; MAP@20 and other cutoffs are descriptive. Final full-test metrics and planned paired contrasts retain negative or inconclusive outcomes. Per-seed user-bootstrap intervals condition on fitted models; sample SD across pipeline seeds describes fitting variability and does not treat repeated users as independent samples. This figure depicts the design, without performance claims.
